# HealthSmile-app
Aplicación de HealthSmile para quue los niños se acostumbren a abrir la boca en eu juego ambientado en Halloween.

## Características
- Crear animaciones
- Detectat la cara y la boca
- contar los segundos que tiene la boca abierta
- Framework Tauri

## Requisitos 
Windows 10/11, Linux o macOS
Node.js 20 o superior
4 GB de RAM

## Instalacción
- git clone https://github.com/mfuentesfailde/reto2.git
- cd proyecto
- npm install
- npm run tauiri build

## Ejecucón
Ejecutar en modo desarrollo:
- npm run tauri dev
